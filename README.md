# COMMANDER v2.0

Personal PC Utility Suite for Windows.

## Features

- WhereIs — whole-PC file search
- SpaceHog — storage analyzer
- LockBox — local file vault
- WhatIsThis — file information
- Focus — timer
- Command Bar — launch commands and programs
- System Monitor
- QuickClean
- File Manager
- Network tools
- Windows Tools
- Clipboard Manager
- Notes
- Settings and Help

## Run

```powershell
python Commander.py
```

Optional dependency for System Monitor:

```powershell
py -m pip install psutil
```
